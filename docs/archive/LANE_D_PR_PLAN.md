## How to build each branch

The history is interleaved (merges from other lanes), so split by **files**, not by commits:

```bash
git switch -c d/1-contract d/0-repo
git checkout lane-d -- sightline/contract.py web/src/contract.ts web/src/contract.schema.json \
    tests/pipeline/test_contract.py tests/pipeline/test_contract_v11.py docs/01_CONTRACT.md
git commit -m "Contract v1.1 and generated types"
```

Each branch must pass on its own before its PR opens:

- `uv run pytest tests/pipeline` (only the tests that branch adds; lane tests come with their lanes)
- `uv run ruff check .`
- for D5/D6: `cd web && pnpm test && pnpm build && pnpm check:offline`

When the last PR merges, `main` must equal `lane-d` for every lane D path:
`git diff main lane-d -- sightline/contract.py sightline/pipeline sightline/api tests/pipeline web/src/shell web/src/lib web/src/review`
prints nothing.

## Things to check while splitting

- Test files that import from a later PR's module (for example a D2 test using `stages`) move to
  the later PR.
- `tests/pipeline/test_code_hygiene.py` scans the whole package; it goes in D4, when all modules exist.
- `.gitignore` conflicts on every merge; keep both sets of lines.
- Keep `web/public/cache/demo/` absent while running web tests (hand-off §4).
- Never commit `data/`, `cache/demo/`, `*.pt`, `.env`.
